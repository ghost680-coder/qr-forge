# QR Forge

A clean, premium QR code generator that works entirely in your browser.

## Features
- 8 data types: URL, Text, Email, Phone, SMS, WiFi, vCard, Location
- Dark glass‑morphism UI
- Download as PNG
- No uploads – everything stays local
