# 🔷 QR Forge – Free QR Code Generator

**QR Forge** is a powerful, lightweight, and completely free QR code generator that works entirely in your browser. No uploads, no sign‑ups, no tracking – just instant QR codes for 20+ data types.

🔗 **Live Demo:** [qr-forge.vercel.app](https://qr-forge.vercel.app)  
📦 **GitHub Pages:** [ghost680-coder.github.io/qr-forge](https://ghost680-coder.github.io/qr-forge/)

---

## ✨ Features

| Category | Supported Types |
|---|---|
| **Basic** | URL, Plain Text, Email, Phone, SMS |
| **Network** | WiFi (auto‑connect) |
| **Contact** | vCard (save to phone) |
| **Social** | Instagram, Twitter/X, Facebook, LinkedIn, TikTok, YouTube, WhatsApp |
| **Apps** | App Store, Google Play |
| **Content** | Event (Google Calendar), Multi URL, PDF, Menu, Review |

### 🔥 Extra Features

- **📸 Image Upload** – Upload a menu photo or logo – it auto‑compresses to fit in a QR code.
- **📄 PDF Support** – Upload small PDFs and encode them directly.
- **⬇️ Download PNG** – Save your QR code as a high‑quality image.
- **📱 Fully Responsive** – Works perfectly on phones, tablets, laptops, and desktops.
- **🔒 100% Private** – All processing happens locally. No data ever leaves your device.
